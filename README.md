# Spotify Web Player Demo

A responsive, Spotify-inspired static web player. This is a local demo; it does
not connect to Spotify or provide Spotify catalog streaming.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file
server. The project has no build step or package dependencies.

## Use the player

- Select **+** in Your Library to add audio files from your device.
- Use the playback bar to play, pause, skip, seek, change volume, shuffle, and
  repeat.
- Search the sample collections or create a playlist for the selected local
  tracks.
- Local audio files must be selected again after reloading the page.

## Deploy on Render

The `render.yaml` Blueprint configures this folder as a static site. In Render,
create a new Blueprint instance and select this GitHub repository. Render will
publish the site and provide its public URL.
